# قاموس المصطلحات

| المصطلح | التعريف | مثال |
|---|---|---|
| Git | برنامج يحفظ نسخ من مشروعك عبر الزمن | مثل "حفظ اللعبة" بنقاط، تكدر ترجع لأي نقطة |
| Commit | نقطة حفظ وحدة بـ Git ويّاها رسالة تشرح شنو تغيّر | `feat: add One Euro filter` |
| venv (بيئة افتراضية) | مجلد خاص بالمشروع بيه مكتباته | `.venv` |
| مكتبة (Library) | كود جاهز كتبه غيرك تستخدمه | mediapipe يتتبع اليد بدالنا |
| نموذج (Model) | ملف "تعلّم" من آلاف الصور شلون يلكه اليد | `hand_landmarker.task` |
| Frame (إطار) | صورة وحدة من فيديو الكاميرا | 30 إطار بالثانية = فيديو ناعم |
| FPS | عدد الإطارات بالثانية | 30 fps = إطار كل 33 ملي ثانية |
| Keypoints / Landmarks | نقاط مهمة يحددها النموذج على اليد | 21 نقطة: الرسغ، المفاصل، الأطراف |
| Bounding Box | أصغر مستطيل يحيط بالشي | المستطيل حول يدك، نستخدمه نعرف إذا مكصوصة |
| Preprocessing | تجهيز الصورة قبل النموذج | عكس المراية، تحويل BGR ← RGB |
| BGR / RGB | ترتيب ألوان البكسل | OpenCV يقرأ أزرق-أخضر-أحمر، والنموذج يريد العكس |
| Normalized | أرقام بين 0 و 1 بدل البكسل | x=0.5 = نص الصورة |
| Hysteresis | عتبتين: وحدة للدخول ووحدة للخروج | مكيف يشتغل على 26 ويطفي على 23 حتى ما يطك كل ثانية |
| Debounce | ما نصدّق التغيير إلا إذا تكرر | 3 إطارات ورا بعض |
| Fixture | بيانات جاهزة للاختبار نعرف جوابها | `pinch.json` = يد قارصة |
| TDD | اختبار أول، بعدين الكود | أحمر ← أخضر |
| Thread (خيط) | عامل ثاني داخل البرنامج يشتغل بالتوازي | واحد يقرأ الكاميرا والثاني يحلل |
| Latency (تأخير) | الوقت بين حركتك وردة الفعل | فلتر قوي = تأخير أكثر |
| Exception | خطأ "ينرمى" ويتمسك | `raise CameraError("BUSY")` |
| class | قالب نصنع منه أشياء إلها بيانات ودوال | `OneEuroFilter()` |
| Enum | قائمة قيم ثابتة بأسماء | `Gesture.PINCH` |
| Process priority | أهمية برنامجك عند الويندوز | Below Normal = البرامج الثانية أول |
